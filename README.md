# homebrew-tap

```bash
brew install maximilianfeix/tap/proxy-scraper
brew install maximilianfeix/tap/spillage
```

- [proxy-scraper](https://github.com/maximilianfeix/proxy-scraper): free proxies that actually work – 700+ sources, every hit verified, a rotating proxy server and an MCP server. Updated here by itself within a day of each release
- [spillage](https://github.com/maximilianfeix/spillage): find the API keys your coding agents spilled into their logs
